## 📝 About

This project implements a **Lexical Analyzer (Lexer)** from scratch, developed without relying on parser generators or external tooling. 

The primary objective is to gain a deep, fundamental understanding of how source code is transformed into structured tokens through **deterministic scanning** and **pattern recognition**. This implementation serves as the foundational first stage of a broader compiler architecture roadmap.

### ⚙️ Features
The lexer is designed to accurately identify and categorize:

* 🔢 **Numeric Literals**: Integer and floating-point representations.
* 🆔 **Identifiers**: User-defined names for variables, functions, etc.
* 🔑 **Keywords**: Language-specific reserved words.
* ⚡ **Operators**: Arithmetic, logical, and assignment symbols.
* 📦 **Delimiters**: Parentheses, braces, and punctuation.
* 🏁 **EOF Detection**: Robust handling of end-of-file markers.
